AS COLLECTION — E-COMMERCE STOREFRONT (VERSION 2)

Included:
- index.html: responsive storefront with product collection, filters, product options, shopping bag and WhatsApp checkout.
- assets/: 19 optimized product photographs supplied by AS Collection. Full garment framing retained; images are not AI-generated or redesigned.

Store features:
- 19 separately listed design/photo entries with product codes AC-001 to AC-019.
- Colour filters: Black, White, Cream, Ivory and Pale Grey.
- Price currently set to Rs. 1,299 per piece (editable in index.html product data).
- Standard sizes M, L, XL and custom measurement option (waist, hip, thigh, trouser length in inches).
- Multiple products can be added to one bag.
- Checkout requests customer name, phone, city, address and payment preference.
- Cash on Delivery and Bank Transfer preference; bank details are not hard-coded.
- WhatsApp order request goes to 03202032350.

IMPORTANT: This is a static storefront prototype, not yet a production-ready e-commerce backend. Orders are sent to WhatsApp and are not saved in a secure database. There is no admin dashboard, live inventory, payment gateway verification, courier integration, automated order status, Meta Pixel or Conversions API yet. Add these before treating it as a complete production store.

Deployment: Upload the contents of this folder (index.html and assets folder) to the GitHub repository used for GitHub Pages. Keep the assets folder beside index.html.
